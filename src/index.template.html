CSV나 백업(JSON) 파일을 여기에 끌어다 놓거나 눌러서 선택
단어장 CSV: 구글 시트에서 파일 → 다운로드 → CSV. 단어 목록을 바꿔요. 동기화를 켜면 필요 없어요.
채점 CSV: 테스트 결과에서 내보낸 CSV를 AI가 채점해 돌려준 파일(또는 채점표). O/X를 테스트 기록에 반영하고 오답 모음을 고쳐요. △는 틀린 것으로 봐요.
백업 JSON: ★·오답 모음·테스트 기록·일별 기록·바꾼 학습상태. 다시 넣으면 지금 기록과 합쳐요(덮어쓰지 않아요). 맥 앱은 ~/Library/Application Support/N3Words/backups/에 날짜별로 자동 백업해요(최근 14일).
