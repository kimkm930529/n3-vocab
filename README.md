# N3 단어

JLPT N3 단어장(구글 시트)을 방향키로 넘겨 보고, 범위를 골라 테스트까지 할 수 있는 개인용 학습 앱.
HTML 파일 하나로 동작하고, macOS에서는 WKWebView 창 하나짜리 네이티브 `.app`으로, 폰에서는 홈 화면에 추가하는 웹 앱(PWA)으로 쓴다.
구글 시트에 붙인 Apps Script로 기기 사이의 학습 기록을 맞추고 단어장도 시트에서 바로 받는다.

## 기능
- **도움말**: 위쪽 `?` 버튼이나 `?` 키(맥 앱은 도움말 메뉴). 처음 켜면 사용법 안내 카드가 한 번 뜬다. 범위 설정·설정·데이터 패널과 도움말 창은 `Esc`로 닫는다
- **학습**: 표제어·히라가나·한글 발음·뜻·예문 카드. `←` `→` 이동, `Space` 뜻 가리기, `F` ★ 표시, `S` 섞기
- **듣기**: OS의 일본어 음성(Web Speech API, 고품질 음성이 깔려 있으면 그것)으로 읽는다. `P` 단어, `E` 예문, `Shift`와 같이 누르면 천천히. 예문과 테스트 결과표의 단어는 눌러서 듣기
- **학습상태 바꾸기**: Pass(완전히 앎)·Good(대체로 앎)·Fail(틀림)·Not Yet(아직 안 봄). 카드에서 `1`–`4`, 또는 카드·목록의 상태 배지를 눌러 나오는 메뉴에서 고른다. 바꾼 값은 단어장과 따로 저장되어 ✎ 표시가 붙고, CSV를 다시 불러와도 남는다. 동기화를 켜 두면 시트의 학습상태 열에 바로 적힌다. 동기화 없이 쓸 때는 설정·데이터 패널에서 **시트 반영용 CSV**(번호·시트 값·바꾼 값, `1. Pass` 표기)를 내보내 시트에 옮겨 적으면, 다음에 단어장 CSV를 불러올 때 시트와 같아진 것은 자동으로 정리된다
- **글자 크기**: 보통/크게/아주 크게 (`+` `−`). 긴 단어는 카드 폭에 맞게 자동으로 줄어든다
- **목록**: 범위 안 단어를 표로 보고 한자·히라가나·뜻·발음·번호로 검색(`/`), 정답률·기출 순 정렬. 줄을 누르면 그 목록 순서로 학습 카드로 이동
- **범위 설정**: 번호 범위(이전/다음 묶음 이동) / 주제(여러 개) / 학습상태(Pass·Good·Fail·Not Yet) / 다락원 day / 기출(기출만·2회 이상·최근 3년·기출 아님) / 표기(한자·가나) / ★만 / 오답 모음만 / 테스트 기록(안 본 단어·취약·발음만 틀림·뜻만 틀림·N일 이상 지남)
- **단어별 기록**: 테스트를 끝내면 단어마다 최근 10회의 발음·뜻 O/X와 날짜를 저장하고 카드 아래에 표시
- **불러오기**: 단어장 CSV를 끌어다 놓으면 목록 교체. 채점 CSV(내보낸 파일을 AI가 채점해 돌려준 것, 또는 채점표)를 넣으면 O/X를 테스트 기록에 반영하고 오답 모음을 갱신 (△는 틀린 것으로 봄). 테스트ID가 없는 채점표도 같은 파일을 다시 넣으면 한 번만 센다
- **테스트**: 출제 방향 6가지 — 단어→발음·뜻 쓰기, 뜻→단어 쓰기, 단어→뜻 고르기, 뜻→단어 고르기, 한자→읽기 고르기, 예문 빈칸→단어 고르기. 쓰기는 발음만·뜻만 묻기, 5개씩 한 화면에 놓고 `Tab`으로 넘기기를 고를 수 있고 자동 O/X 추정(수정 가능). 고르기는 `1`–`4` 키이고, 고르면 바로 정답을 색으로 보여 준다(끌 수 있음). 문항 수는 기본 20개이고 마지막 선택을 기억한다. 끝나면 틀린 단어는 오답 모음에 자동으로 넣고 맞힌 단어는 빼며, 결과 화면에서 반영을 취소할 수 있다. 틀린 것만 재시험. 쓰기 테스트는 적은 답을 `test_raw` 형식 CSV로 내보내기(정답·테스트ID 포함)
- **기록**: 날짜별로 학습 카드로 본 단어 수, 테스트 횟수·문항·정답을 쌓아 보여 주고 CSV로 내보내기. 맥 앱은 `~/Library/Application Support/N3Words/daily_log.csv`에도 자동 저장

- **백업**: 설정·데이터 패널의 **백업 내보내기**로 ★·오답 모음·테스트 기록·일별 기록·바꾼 학습상태를 JSON 하나로 저장. 다시 끌어다 놓으면 지금 기록과 합친다(덮어쓰지 않음). 맥 앱은 `~/Library/Application Support/N3Words/backups/`에 날짜별로 자동 백업(최근 14일)

★·학습상태 변경·오답 모음·테스트 기록·일별 기록·보던 위치·진행 중인 테스트는 localStorage에 저장된다 (맥 앱은 `~/Library/WebKit/local.kevin.n3words/`). 기기마다 따로이므로 맥과 폰을 같이 쓰려면 아래 동기화를 켠다.

## 동기화 (구글 시트 + Apps Script)
서버 없이 단어장 구글 시트에 Apps Script를 붙여 웹 앱으로 쓴다. 한 번만 설정하면 된다.

앱의 **설정·데이터 → 동기화 옆 ?** 를 누르면 같은 안내가 단계별로 나오고, **코드 복사** 버튼으로 Apps Script 코드를 바로 복사할 수 있다.

1. 단어장 시트에서 **확장 프로그램 → Apps Script**를 열고 `Code.gs` 내용을 앱의 **코드 복사**(또는 `dist/sync.gs`) 내용으로 바꿔 저장한다 (단어장 탭 이름이 `N3단어장`이 아니면 맨 위 `WORDS_SHEET`를 고친다)
2. 함수 목록에서 `setup`을 골라 **실행** → 권한 허용 → 실행 로그에 나온 **비밀 값**을 복사한다
3. **배포 → 새 배포 → 웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자** → 배포하고 웹 앱 URL(`…/exec`)을 복사한다
4. 맥 앱의 **설정·데이터** 패널에 URL과 비밀 값을 넣고 **저장**
5. **📱 다른 기기 연결**을 누르면 폰 앱 주소를 넣은 연결 링크와 QR(맥 앱)이 나온다. 폰에서 QR을 찍거나 링크를 열면 설정이 들어간다. iPhone 홈 화면 앱은 Safari와 저장 공간이 따로라, 홈 화면 앱의 웹 앱 주소 칸에 연결 링크를 붙여 넣고 저장한다

위쪽 **동기화** 표시가 초록이면 정상, 노랑은 주고받는 중, 빨강은 실패다(누르면 이유가 보인다). 그 뒤로는 앱을 켤 때, 앱으로 돌아오거나 떠날 때, 기록이 바뀌고 15초 뒤에 알아서 주고받는다(**지금 동기화**로 바로 할 수도 있다).

- 합치는 규칙(`src/state.js`): 테스트 기록·일별 기록은 테스트ID 기준으로 합치고, ★·오답·학습상태처럼 켜고 끄는 값은 나중에 바꾼 쪽을 따른다. 끈 것과 "테스트 기록 지우기"도 다른 기기에 전해진다
- 학습 기록은 시트의 숨긴 탭 `_n3sync`에 JSON으로 보관된다. 앱에서 바꾼 학습상태는 단어장 탭의 학습상태 열에 `1. Pass` 형식으로 적힌다
- 단어장은 시트가 바뀌었을 때만 받아 온다. 그래서 동기화를 켜면 CSV를 내려받아 넣을 필요가 없다
- 비밀 값은 앱에 넣지 않고(빌드 결과에도 없음) 기기마다 입력한다. 웹 앱 URL과 비밀 값을 아는 사람은 기록을 읽고 쓸 수 있으니 공유하지 않는다. 비밀 값을 바꾸려면 Apps Script의 프로젝트 설정 → 스크립트 속성에서 `TOKEN`을 지우고 `setup`을 다시 실행한다
- `sync.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영된다

## 폰에서 쓰기 (PWA)
개인용 배포 주소: [N3 단어장](https://n3-vocab-mobile.f798f23e-da7d-41fa-a3ff-a2e4cd2d05c4.chatgpt.site)

Sites의 공유 설정은 현재 공개(링크가 있는 모든 사용자)다. 단어장은 로그인 없이 열리지만, 학습 기록은 기기별 저장소에 있으므로 기록을 이어 쓰려면 별도로 동기화를 연결해야 한다. 동기화 비밀 값은 공개 배포 파일에 넣지 않는다.

- **iPhone·iPad**: Safari에서 주소 열기 → 공유 → 홈 화면에 추가. 표시되면 **웹 앱으로 열기**를 켠다
- **Android**: Chrome에서 주소 열기 → 메뉴 → 앱 설치 / 홈 화면에 추가
- 설치한 아이콘으로 앱을 열고 온라인 상태에서 한 번 기다린다. 위쪽 **홈 화면에 추가** 안내에서 오프라인 준비 상태를 볼 수 있다. 단어·카드·테스트·기록은 기기에 저장되며, 일본어 듣기의 오프라인 동작은 기기의 음성 설치 상태에 달려 있다
- 맥의 기록을 이어 쓰려면 맥 앱의 **설정·데이터 → 다른 기기 연결**에서 이 배포 주소를 넣어 연결 링크를 만든다. 홈 화면 앱의 **설정·데이터**에 그 링크를 붙여 넣고 저장한다. 동기화를 아직 설정하지 않았다면 먼저 위의 구글 시트 동기화 설정을 한다

웹만 다시 빌드할 때는 `python3 scripts/build.py --web-only`를 쓴다(Swift 컴파일 없이 기존 맥 앱을 보존). 배포 소스는 `sites/n3-vocab-mobile/`의 별도 Sites 저장소에 있고, `.openai/hosting.json`에 사이트 ID를 유지한다. 다시 배포할 때는 `dist/web/` 내용을 해당 저장소의 `dist/`에 반영한 뒤 Sites 소스 저장·배포 절차를 사용한다. 동기화 URL·비밀 값과 개인 학습 기록은 배포 파일에 넣지 않는다.

`dist/web/`(앱, manifest, service worker, 아이콘)을 정적 호스팅에 올리고 폰 브라우저로 연 뒤 **홈 화면에 추가**하면 앱처럼 뜬다. 한 번 열어 두면 오프라인에서도 열린다.

- 호스팅: Cloudflare Pages나 Netlify에 `dist/web` 폴더를 끌어다 놓으면 HTTPS 주소가 생긴다 (service worker는 HTTPS에서만 동작). 단어장이 같이 올라가므로 주소는 공유하지 않는다
- iPhone은 Safari → 공유 → 홈 화면에 추가, Android는 Chrome 메뉴 → 홈 화면에 추가 / 앱 설치
- 새로 빌드해 다시 올리면 다음에 앱을 열 때 새 버전을 받아 둔다
- 맥 앱 전용 기능(AI 채점 폴더, 자동 백업, `daily_log.csv`)은 폰에 없다. 기록은 동기화로 맞춘다

### AI에게 채점 맡기기
1. 쓰기 테스트 결과 화면에서 **채점용 CSV 내보내기**
2. 파일을 AI에게 주고 `자가채점(발음)`·`자가채점(뜻)` 열(뜻→단어 쓰기는 `자가채점`)을 O/X로 고쳐 CSV로 돌려 달라고 한다. 정답 열이 같이 들어 있어 단어장을 따로 줄 필요가 없다
3. 돌려받은 CSV를 앱 창에 끌어다 놓는다. `테스트ID` 열로 어느 테스트인지 찾아 그 기록을 고치므로 두 번 세지 않는다

#### 맥 앱: 폴더로 자동 주고받기
맥 앱에서는 파일을 손으로 내보내고 끌어다 놓지 않아도 된다. `~/Library/Application Support/N3Words/grading/` 아래 폴더 셋을 쓴다 (설정·데이터 패널의 **폴더 열기**로 열 수 있다).

| 폴더 | 내용 |
|---|---|
| `outbox/` | 쓰기 테스트(단어 → 발음·뜻 쓰기, 뜻 → 단어 쓰기)를 마치면 `test_raw_<테스트ID>.csv`가 자동으로 생긴다. 결과 화면에서 O/X를 고치면 같은 파일을 덮어쓴다 |
| `inbox/` | 채점된 CSV를 넣는 곳. 앱을 켤 때와 앱 창으로 돌아올 때 읽어서 반영한다 |
| `done/` | 반영이 끝난 파일이 옮겨지는 곳 |

Claude(Claude Code나 Cowork처럼 이 폴더를 읽고 쓸 수 있는 곳)에게는 이렇게 부탁하면 된다:

> `~/Library/Application Support/N3Words/grading/`의 outbox의 최신 파일을 채점해서 inbox에 넣어줘

채점 열만 O/X로 고치고 나머지 열(특히 `테스트ID`)과 CSV 형식은 그대로 두어야 한다. 형식이 맞지 않는 파일은 `inbox/`에 그대로 남고 앱이 파일 이름을 알려 준다. 앱에 API 키를 넣지 않으며, 앱이 직접 AI를 부르지는 않는다.

## 폴더
```
src/index.template.html   앱 본체 (단어 데이터 자리에 __DATA__, 합치는 규칙 자리에 /*__STATE_JS__*/)
src/state.js              학습 기록을 합치는 규칙 (앱과 Apps Script가 같이 씀)
data/words.csv            기본 단어장 (구글 시트 → 파일 → 다운로드 → CSV)
macos/                    .app 껍데기 (main.swift, Info.plist, 아이콘)
scripts/build.py          빌드 스크립트 (swiftc 필요: `xcode-select --install`)
scripts/sync.gs           구글 시트 동기화 Apps Script (빌드하면 state.js를 붙여 dist/sync.gs로)
scripts/migrate_from_chrome.py   예전 Chrome 창 버전의 데이터를 맥 앱으로 옮기기
tests/                    node 테스트 (합치는 규칙, 앱 스크립트 문법)
results/                  테스트 원본 / 채점표 기록
```

## 빌드
```bash
python3 scripts/build.py
```
`dist/`에 `index.html`(브라우저로 바로 열기), `N3 단어.app`, `N3_단어_app.zip`, `web/`(폰용 PWA), `sync.gs`가 생긴다.

테스트 (Node 18 이상):
```bash
node --test tests/*.test.js
```

## 설치 (macOS)
```bash
cp -R "dist/N3 단어.app" /Applications/
xattr -dr com.apple.quarantine "/Applications/N3 단어.app"   # 다운로드한 zip일 때만 필요
```
독에 자체 아이콘으로 뜨는 일반 맥 앱이고, 창 크기와 위치를 기억한다.

예전 Chrome 창 버전에서 쓰던 데이터는 `python3 scripts/migrate_from_chrome.py`를 실행한 뒤 앱을 다시 열면 넘어온다.

## 단어장 업데이트
1. 구글 시트 `N3단어장` 탭을 CSV로 내려받아 `data/words.csv`를 교체 (열: 번호·학습상태·주제·한자/표기·히라가나·한국어 뜻·예문·예문 한글뜻·한글 발음·학습 메모·다락원)
2. `python3 scripts/build.py` → 새 앱 설치
   (앱을 다시 만들지 않고, 실행 중인 앱에 CSV를 끌어다 놓아도 된다. 동기화를 켜 두었다면 시트만 고치면 된다)

학습상태는 `1. Pass`처럼 적혀 있어도 Pass / Good / Fail / Not Yet 넷으로 맞춰 읽는다.
내장 단어장이 바뀐 새 빌드를 설치하면, 앱에 끌어다 놓았던 예전 CSV 대신 내장 단어장을 쓴다.
